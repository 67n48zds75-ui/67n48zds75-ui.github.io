# Корневой сайт MathLab

Статические файлы для репозитория `67n48zds75-ui/67n48zds75-ui.github.io` и корневого адреса `https://67n48zds75-ui.github.io/`.

Основное приложение остаётся по прежнему адресу: **https://67n48zds75-ui.github.io/-/**. Исходники приложения находятся в репозитории `67n48zds75-ui/-`. Его адрес, данные и существующее подтверждение Google здесь не изменяются.

## Назначение

- `index.html` — небольшая страница с прямой ссылкой на тренажёр; без JavaScript, автоматического перенаправления и копии приложения. Она предназначена для обычной статической выдачи HTTP 200.
- `yandex_941d9b9efc6d3bde.html` — точная копия предоставленного владельцем HTML-файла подтверждения Яндекса. После публикации ожидается адрес `https://67n48zds75-ui.github.io/yandex_941d9b9efc6d3bde.html`.
- `robots.txt` — корневой файл, разрешающий обход и указывающий существующую карту основного приложения.
- `.nojekyll` — отключает обработку файлов Jekyll.

Только у главной страницы `index.html` установлен `meta robots` со значением `noindex, follow`, чтобы эта служебная страница не создавала конкурирующий индексируемый адрес. Это не запрет индексации основного приложения в `/-/`. В `robots.txt` запрета обхода нет.

## Публикация

После создания репозитория и загрузки этих файлов включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Дождитесь публикации и проверьте, что файл подтверждения Яндекса доступен с HTTP 200 и точным содержимым. Затем можно нажать «Подтвердить» в Яндекс Вебмастере для ресурса `https://67n48zds75-ui.github.io/`.

Не удаляйте файл подтверждения после успешной проверки. Размещение файла само по себе ещё не подтверждает права в кабинете и не означает индексацию.

## Текущее состояние

Файлы загружены, GitHub Pages автоматически включён из ветки main и корневой папки. Подтверждение Яндекса по корневому URL проверено: HTTP 200 и точное содержимое. Основное приложение продолжает работать по прежнему адресу `/-/`. Владелец должен завершить проверку кнопкой «Подтвердить» в Яндекс Вебмастере; успех в личном кабинете и индексация пока не заявляются.
